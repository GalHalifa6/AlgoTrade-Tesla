# AlgoTrade

## 📌 Overview
AlgoTrade is a Jupyter Notebook project for experimenting with **algorithmic trading strategies**.  
It allows importing market data, applying trading logic, and backtesting performance.

## 🛠️ Requirements
Install required dependencies:
```bash
pip install -r requirements.txt
```

## 🚀 Usage
Run the notebook:
```bash
jupyter notebook algoTrade.ipynb
```

## 📊 Features
- Data loading and preprocessing
- Trading strategy implementation
- Backtesting and performance evaluation
- Visualization of results
